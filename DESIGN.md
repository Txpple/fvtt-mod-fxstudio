# fxstudio — design notes

What was decided and measured while building, kept beside [PLAN.md](PLAN.md) (the plan) and
[BACKLOG.md](BACKLOG.md) (what is parked and why). Phase 0 (foundation) is built; the numbers
below are from the import run of 2026-09-06 and are re-measured by the tools, never hand-carried.

## 1. Two corpora and a buffer, later wins

- `recipes/baseline.json` — the D&D5e Animations 3.3.0 preset, converted row for row (1289 rows),
  GPL-3 (`recipes/BASELINE-LICENSE`), read-only, regenerated by `tools/import-aa.mjs --write`.
- `recipes/house.json` — the user's own looks, MIT, committed, portable. Starts with what this
  world had changed over the preset at import: three edited preset rows and four item flags.
- the world setting `fxstudio.looks` — the live edit buffer the screens write (phase 2);
  `tools/export-looks.mjs` folds it into `house.json` (phase 2).

Resolution order: world buffer → house → baseline → nothing. A house row with `off: true` switches
a baseline look off.

## 2. The row

```
{ name, menu, match?, exclude?, effectType?, presetType?, fx: [layer…], thrown?, soundOnly?, off?, note? }
layer = { preset, video, aa?, returnAa?, file, twin?, sound?, options }
```

- `menu` is the Automated Animations menu the row came from and therefore the preset that plays
  it: `melee`, `range`, `ontoken`, `templatefx`, `aura`, `preset`, `aefx`. It is not a moment; the
  reader (phase 1) decides which rows a moment may play, exactly as AA's hooks did.
- `video` is AA's descriptor `{dbSection, menuType, animation, variant, color}`, kept verbatim
  because AA's sequences branch on it (claw and bite sizing, "complete" loops never fade out,
  returning weapons, dagger and hammer return delays).
- `aa` is the path the layer plays through, `autoanimations.…` as AA wrote it, served by this
  module's private table (§3). `file` is the readable twin: the native `jb2a.*` path with the
  same files where one exists (`twin: "exact"`, 36 layers), else the JB2A family the files belong
  to (`twin: "family"`, 1191 layers, a superset), else the raw file path AA had as a custom path
  (530 layers; `missing: true` when this install lacks the file — one, `Map.png`).
- `sound` is `{file, volume, delay, startTime, repeat, repeatDelay}` after AA's own defaulting;
  the delay already includes the layer's delay when the layer does not wait.
- `options` is the whole option set for the layer's menu with AA's defaults applied — every
  field, not only the ones that differ — so a preset can play a row without knowing AA's tables.
- `thrown` carries the melee "switch to a ranged weapon when the target is out of reach" (122
  rows), `soundOnly` and `macro` are carried but empty in this corpus (0 and 0).
- Preset rows (teleport, projectile-to-template, dual-attach, thunderwave) carry AA's sanitized
  preset data with each video part resolved the same way.

## 3. The private table (why `fxstudio.aa.*` exists)

AA does not play JB2A's own database paths. It registers its own copy of a JB2A subset as
`autoanimations.*`, with its own Sequencer metadata: five `_template` markers and 48 `_markers`
against JB2A's 148 and 108. Measured on the corpus: for 1178 of the layers, the native `jb2a.*`
path that holds the same files carries a different template (`[100,0,0]` under AA against
`[200,300,300]` for a JB2A melee family, for instance), which changes how Sequencer stretches
and times the effect. Zero loss is the locked decision, so the module ships the subset of AA's
table the corpus uses (`recipes/aa-database.json`, 325 variant nodes, 1576 Sequencer entries,
MIT with attribution) and registers it verbatim as Sequencer module `fxstudio`, so a baseline
row's `aa` path resolves to byte-identical files and metadata. The `jb2a.*` twin is for reading
and for the house corpus: a new look written by the user names a native path.

The parity proof (`import-aa` step 4) compares, for every world row: AA's own reading of the
entry (a line-for-line port of its DataSanitizer and path builder, `tools/lib/aa-port.mjs`)
against what the resolver returns for the row's label — the same file set through the private
table, coverage through the JB2A twin, the same sound files, the same option values, the same
metadata. 1289 of 1289.

## 4. Matching, as AA did it minus the accidents

`scripts/corpus.js` is pure and runs unchanged in node, so the tools prove the same lookup the
module runs.

- The whole name, case and spacing aside. Never a substring: "Stabilize" no longer plays "Stab",
  "(free casting)" no longer plays "Sting".
- A qualifier dnd5e appends is tried after the whole name: "Misty Step - Spellcasting" (an NPC's
  spell), "Bless - Fey-Touched" (a granted spell), "Potion of Healing (Greater)". This is still
  the ability's own name; 13 names on the world's actors reach their row this way.
- A weapon or creature-attack row (`match: "word"`, the melee and range rows whose AA type is
  not "spell") names the END of the ability's name as whole words, with an optional plural and a
  trailing "+1" or parenthesis: "Light Hammer", "Sera's Shortsword", "Talons", "Bite (wolf form)".
  Not "Shield of Faith" for "Shield", not "Maul of Momentum" for "Maul" (see BACKLOG).
- A row AA flagged "exact match" beats a same-named row it did not, as AA searched those first
  (Witch Bolt: the preset row, not the range row). Among equals, AA's menu order.
- `on: "use"` searches melee, range, ontoken, templatefx, aura, preset; `on: "template"` replaces
  a melee/range/ontoken hit by the templatefx row of the same name; `on: "effect"` searches aefx.
- Eight rows AA could never reach for their own label (a same-length label earlier in its sort
  won) are reachable now; the import report lists them.

The matching census (`import-aa` step 5) runs every item on the world's actors and in the PHB
packs through both lookups. 713 names: 585 agree; 93 play under AA only (substring and activity
name accidents, each listed for the user to keep or drop); 34 differ; the effects differ on 19
(all "Skill Guidance" variants that AA matched to "Guidance").

## 5. Tools

Offline, seconds, no Foundry: `import-aa.mjs` (the migration and its proof), `check-looks.mjs`
(every path in both corpora and the private table against the libraries' registration files
and the disk; the Check screen will run the same test live). Live, read-only: `smoke-boot.mjs`.
Sandbox operations: `sandbox-module.mjs`. See [tools/README.md](tools/README.md).
