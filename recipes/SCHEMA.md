# The FX grammar (schema 2)

This is the one grammar FX Studio reads and writes (ARCHITECTURE §4, §7). The screens compose it
from pickers, an assistant writes it as data, the files hold it, and the module reads all three the
same way. `scripts/core/fx.js` is the code; this page is the grammar with every knob's meaning,
range and default, for a person or an assistant writing an FX by hand.

The sentence is generated from the FX, never parsed back:

```json
{ "id": "fire-bolt",
  "for": ["spell:fire-bolt"],
  "on": "use",
  "scenes": [
    { "shape": "shoot", "asset": { "path": "jb2a.fire_bolt.orange" },
      "sound": { "asset": "psfx.cantrips.fire-bolt", "volume": 0.75 } }
  ],
  "by": "the migration", "at": "2026-09-06", "note": "D&D5e Animations 3.3.0" }
```

reads as *Fire Bolt · when used · a bolt (JB2A fire bolt, orange) shoots from the caster to each
target and flies past on a miss · with the PSFX cantrips fire-bolt sound.*

## The files

| File | What | Licence |
| --- | --- | --- |
| `stock/spells.json`, `weapons.json`, `natural.json`, `features.json`, `items.json`, `effects.json` | the migrated D&D5e Animations corpus, one file per subject kind, read-only, regenerated by `tools/migrate-aa.mjs` | GPL-3 (`STOCK-LICENSE`) |
| `house.json` | the user's FX and overrides — the only home of an Item Hook; Save writes it in the module folder on the server (`tools/pull-corpus.mjs` brings the file into the repo) | MIT |
| `starters.json` | the abstract FX every new FX starts from (`starter:bolt`, …) | MIT |
| `aa-assets.json` | the frozen asset table: what the migration could not point at the libraries' own paths; counted, meant to reach zero | MIT |
| `records.json` | **the records**: every key the closed lists hold, addressed — `{uuid, name, where, on?, of?}` keyed by the key. Where a key's evidence lives, written down at the moment the key is earned (`tools/records.mjs`). Since 2026-09-09 every keyed FX carries its own copy (`record`), stamped from this file, and this file is the **address book for the 3155 keys that have no FX yet** plus the source of every stamp and the fallback the screens read by key. The engine never reads it; the screens read it when the window opens | MIT |
| an item's flag `fvtt-mod-fxstudio.FX` | the item pointer: one specific item names an FX id of its own (set from the screens with "only this one"); it answers ahead of every key, and such an FX has an empty `for` | — |

Every file is `{ "_meta": {...}, "fx": [FX, …] }` with `_meta.schema: 2`. Resolution order:
`house.json`, then the stock — later wins per FX id, and per subject key. There is no draft layer
(2026-09-12): an FX is in a file or it is nothing, and Save writes the file — a Stock FX's edit is
either a House override (the same id in `house.json`) or the stock file itself.

## An FX

| Field | Required | Meaning |
| --- | --- | --- |
| `id` | yes | lower-case letters, digits and dashes; unique across the corpora. A house FX with a stock FX's id replaces it. |
| `for` | yes (may be empty for a starter) | the subject keys it answers, see *Keys*. An FX answers the first key of a subject's list that has an FX. |
| `record` | no, but every keyed FX in the corpora carries one | **where its key's evidence lives, on the FX**: `{uuid, name, where}` plus `on` (the creature a natural attack sits on) and `of` (how many share it). STAMPED by every writer from `records.json` at the moment it writes — never typed. It is what makes an FX file complete on its own, so it can be exported, handed to someone else and read without a second file. |
| `on` | yes | the moment kind: `use` (an ability used — the attack roll for attacks, the damage roll for saves and heals, the template placement for areas, the card for the rest), `effect` (an active effect created or switched on), or one of Battle Flow's words when the table runs Battle Flow — `maneuver` (a Combat Superiority die rides a hit or answers a hold), `sneak` (Sneak Attack's dice ride a hit), `fold` (a die folds into a d20 test), `rider` (a clock rider's damage rides a hit), `hold-answered` (a held roll is answered by a cast). A Battle Flow moment whose ability posts no card (`maneuver`, `sneak`, `fold`, `rider`) plays the ability's `use` look when nothing is authored for the word, so most need no row of their own; a look keyed `event:<word>` answers every ability at that moment. |
| `off` | no | `true`: this FX silences its `for` keys — they play nothing. Needs no scenes. |
| `scenes` | yes | the pictures and sounds, in start order. Always this FX's own — see *No shortcuts* below. |
| `by`, `at`, `note` | no | provenance: who wrote it (a name, an assistant, "the migration"), the ISO date, and why in a sentence. |

An FX needs a placed template when any of its scenes is a `fill` or names `template` as a place;
with two FX for one key, the one that needs the template answers a template moment and the other
answers the rest.

## Keys

`<kind>:<id>`, optionally `/<activity type>` for the most specific form. The reader builds a subject's
keys most specific first; an FX is found by the first key that has one.

| Kind | Id | Example keys, most specific first |
| --- | --- | --- |
| `spell` | dnd5e's identifier (`system.identifier`, else the slug of the name) | `spell:fire-bolt/attack`, `spell:fire-bolt` |
| `weapon` | the slug of the name, then the base weapon (`system.type.baseItem`) | `weapon:maul-of-momentum`, `weapon:maul` |
| `natural` | the slug of the name (a weapon whose type is natural) | `natural:bite` |
| `feature` | dnd5e's identifier | `feature:brutal-strike` |
| `item` | the slug of the name (consumables, equipment, tools, loot) | `item:potion-of-healing` |
| `effect` | the slug of the effect's name, then its origin's keys | `effect:shield`, then `spell:shield` |
| `event` | Battle Flow's moment word, the last key of a moment it publishes | `event:sneak`, `event:fold` |

(`status` and `damage` were placeholders for phase 4's outcomes and went on 2026-09-12; a kind is added with the reader that produces it.)

The slug is Foundry's strict slugify after dnd5e's identifier rule: lower case, letters, digits and
dashes, everything else dropped ("Melf's Minute Meteors" → `melfs-minute-meteors`,
"Blindness/Deafness" → `blindness-deafness`). A trailing qualifier is tried after the whole name:
"Misty Step - Spellcasting" also gives `spell:misty-step`; "Potion of Healing (Greater)" also gives
`item:potion-of-healing`. A "cast spell" activity puts the linked spell's keys first; an ammunition's
keys come before the weapon's. Nothing is ever matched by a substring or a word.

## A scene

`shape` says what the picture does; every other knob is named for what it does and means the same in
every shape. Only the knobs a shape reads are allowed on it (the validator names any other).

| Shape | The picture | Reads |
| --- | --- | --- |
| `strike` | a swing at the caster, rotated toward each target and moved toward it when out of reach; can miss; `thrown` swaps in a flight beyond reach | common, `to`, `size {tokenWidths}`, `mirror`, `onMiss`, `thrown` |
| `shoot` | a picture stretched from a place to a place; can miss; a return flight | common, `from`, `to`, `mirror`, `onMiss`, `return`, `scatter` |
| `mark` | a static picture at a place, sized to the token, as a radius, in squares, or to the placed object; once or persistent | common, `at`, `size`, `mask`, `persist`, `attach`, `follow`, `face`, `rotate`, `anchor`, `fadeIn`, `fadeOut`, `mirror`, `onMiss` |
| `fill` | a picture sized to the placed template's shape (circle, cone, line, rectangle) | common, `size {fit: "shape"}` or `{squares}`, `mask`, `persist`, `rotate`, `anchor`, `clearTemplate` |
| `aura` | a persistent picture attached to a token, sized as a radius, breathing and pulsing | common but `repeat`/`every`, `at`, `size {radius}`, `attach`, `breathe`, `pulse`, `fadeIn`, `fadeOut` (always persistent) |
| `beam` | a picture attached at both ends, standing until ended | `asset`, `sound`, `rate`, `opacity`, `below`, `elevation`, `from`, `to`, `persist` |
| `move` | the token itself: fades, travels or jumps to the destination — a jump is a teleport with Foundry's own `displace` action, across walls and creatures; the spot is judged by the words first | `sound`, `range`, `speed`, `fade`, `after`, `jump`, `seen`, `unoccupied` |
| `sound` | a sound on its own | `asset`, `volume`, `delay`, `start`, `repeat`, `every`, `wait` |
| `custom` | the escape hatch: Sequencer calls as data against a whitelist; read as "a custom effect" | `calls` |

**Common knobs** (every picture shape): `asset`, `sound`, `delay`, `wait`, `repeat`, `every`, `rate`,
`fadeIn`, `fadeOut`, `opacity`, `tint`, `below`, `elevation`, `zIndex`, `anchor`, `note`.

### Assets

| Form | Meaning |
| --- | --- |
| `"jb2a.fire_bolt.orange"` or `{ "path": "…" }` | a library path (JB2A's, PSFX's or the frozen table's own registration) |
| `{ "paths": ["…", "…"] }` | one of several, chosen at random each time (library paths or raw files) |
| `{ "file": "modules/…/x.webm" }` | a raw file |
| `{ "family": "jb2a.fire_bolt", "colour": "orange", "variant": "01" }` | the same path in parts |
| `{ "byPosition": { "center": …, "mid": …, "left": … } }` | three assets, picked by where the template sits against the caster (a thunderwave); pairs with `rotate: "by-position"` |
| `+ "colour": "black"` | a colour swapped into the path's last segment; the family must list it (`tools/assets.mjs` shows what it lists) |
| `+ "template": [grid, start, end]` | Sequencer's stretch metadata for this picture, only where the migration had to keep AA's |

A sound is `{ asset, volume, delay, start, repeat, every, wait }`; `volume` 0.75, `delay` 0, `start`
0 ms into the file, `repeat` 1, `every` 250 ms.

### Places

`source` the caster · `each-target` every targeted token · `targets-else-source` the targets, or the
caster when nothing is targeted · `both` the caster and the targets · `template` the placed template
· `destination` the spot a move goes to · `impact` where the previous scene's pictures landed, per
target, a miss included · `area` a random spot inside this FX's standing area picture, else the
caster.

`at` is for a picture that stays put; `from` and `to` for one that travels.

### Sizes

`{ "tokenWidths": n }` n token widths (the token as drawn, image scale and ring included) — a swing
is 5, a mark 1.5 · `{ "radius": r, "plusToken": true }` r squares around, the token's own width added
when asked · `{ "squares": n }` n grid squares · `{ "fit": "shape", "scale": {x, y} }` the placed
template's measured shape · `{ "fit": "object", "scale": n }` the placed object's bounds.

### Timing and FX

| Knob | Meaning | Default |
| --- | --- | --- |
| `delay` | ms before the scene starts (negative starts it early against the previous wait) | 0 |
| `wait` | `true`: the next scene starts after this one finishes (plus `delay` ms); a number: after that many ms | false |
| `repeat`, `every` | play the picture n times, ms apart | 1, 250 |
| `rate` | playback speed | 1 |
| `fadeIn`, `fadeOut` | ms | mark 250/500, aura 250/500, others 0 |
| `opacity` | 0–1 | 1 |
| `tint` | `{ colour, contrast, saturation }` | none |
| `below` | under the tokens | false |
| `elevation` | `{ level, absolute }` | the token's |
| `zIndex` | draw order among pictures | 1 |
| `anchor` | `{ x, y }` | 0.5, 0.5 (a cone or line fill: 0, 0.5) |
| `mirror` | `"random"` flips the picture at random; `"none"` | strike and shoot: random |
| `onMiss` | `fly-past` (a bolt flies past), `play` (a swing plays as a miss), `skip` | shoot: fly-past; strike, mark: play |
| `persist` | `none` · `effect` (while the tying effect stands) · `template` (while the Region stands) · `until-removed` | mark and fill: none; aura and beam: until-removed |
| `attach` | `{ alpha, visibility }`: a persistent picture follows the token's fading and hiding | both false |
| `follow` | a once-only mark that still follows its token while it plays | false |
| `face` | `"away-from-source"`: the mark points away from the caster | — |
| `rotate` | degrees, or `"by-position"` (a fill turned to where the template sits) | 0 |
| `mask` | clipped to the token or the template | false |
| `scatter` | a bolt lands a little off the mark | false |
| `clearTemplate` | the placed template is removed once the scene has played | false |
| `return` | `{ asset }` a flight back from where the bolt landed (shoot) | — |
| `thrown` | `{ asset, return: {asset}, sound, reach }` what flies when the target is beyond reach; `reach` "auto" (five feet, plus one square for a reach weapon) or squares | — |
| `breathe`, `pulse` | `{ min, max, every }` an aura's scale and opacity loops | — |
| `range`, `speed`, `fade`, `after`, `jump`, `seen`, `unoccupied` | a move: feet of range; grid squares per second when travelling; `{to, after, back}` the token's fade; ms before the token is placed; place it (true) or travel (false); what the spell's words demand of the spot — `seen`: a space the caster can see (a sight-blocking wall between refuses it; Dimension Door says `false`), `unoccupied`: no creature stands there. A refusal is a notice at the click, or a ledger line for a given destination, and nothing plays | 30, 120, none, 0, true, true, true |

### Custom

`calls` is a list of `[method, ...args]` run on the Sequence in order: `["effect"]`, `["sound"]` and
`["animation"]` start a section, `["wait", ms]` waits, anything else is called on the current
section. A place word in an argument (`"source"`, `"each-target"`) is resolved to the moment's
tokens. Only the methods in `CUSTOM_WHITELIST` (core/fx.js) are allowed. Rare by design: a knob
every FX can use is always better than a custom scene one FX uses.

## Writing an FX: the assistant's round trip

1. `node tools/census.mjs` — what plays nothing, per sheet, with each subject's keys.
2. Pick a starter (`starters.json`) or an existing FX to copy the scenes of (`api.fx.scenesOf(id)`, or read the file).
3. `node tools/assets.mjs "misty step"` — the libraries' own families, variants and colours; a path is looked up, never guessed.
4. Write the FX as data, in full. A variant is a COPY: "Sharran Step is Misty Step in black" means Misty Step's scenes written out again with the colour changed — `{ "id": "sharran-step", "for": ["spell:sharran-step"], "on": "use", "scenes": [ …Misty Step's scenes, in dark_black… ] }`. Longer to write, and it stands on its own.
5. `node tools/check-fx.mjs <file>` — every problem in a sentence; every asset against the registration and the disk.
6. `node tools/preview.mjs <file or FX id>` — plays it on the sandbox fixture.
7. Propose it: in the game through `api.fx.save(fx, {by, to})` (into `house.json` or the stock file on the server, with provenance; `tools/pull-corpus.mjs` brings it into the repo), or as a change to `house.json` in a pull request.
